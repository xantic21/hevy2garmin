# hevy2garmin portfolio icon · design and attribution

The graphic in [icon.svg](icon.svg) is an **original xantform portfolio icon** (formerly the xantic21 portfolio illustration) for GitHub documentation only. It is deliberately distinct from the application's original upstream icon.

- **Canvas:** 108 × 108 SVG, 26-unit corner radius, consistent with the xantic21 portfolio icon family.
- **Palette (xantform Design System 2.0, 25 November 2026):** light tile `#E6F3EE`, dumbbell in ink `#1F5A4D` (7.01 : 1), synchronization arrow in medium `#A4C7B7`; tonal dark variant on `#253F38`. Geometry unchanged from the earlier portfolio illustration; the arrow moved from `#309780` to the approved secondary tone.
- **Meaning:** strength-training activity plus transfer/synchronization to Garmin Connect.
- **Presentation surfaces:** this repository's README, hero and social preview, the public `xantic21/xantic21` profile, and `henning-hub`'s GitHub portfolio home use the same SVG geometry. The hero and social preview embed the identical tile; the profile and portfolio copies are byte-identical to `icon.svg`. The social preview previously showed an unrelated check-mark motif and now uses the icon.
- **Not an upstream logo:** this illustration is **not** endorsed by, authored by, or represented as the original project/app icon from [drkostas/hevy2garmin](https://github.com/drkostas/hevy2garmin).
- **Unchanged application asset:** the original `src/hevy2garmin/static/favicon.svg` remains the source for the fork's app/favicon. The source code, licensing, functionality, deployments and releases are untouched.

Maintain explicit upstream author, upstream repository and license attribution wherever the fork is described. Do not overwrite the original app/favicon SVG with this portfolio illustration.
